Working model

A first milestone should remove uncertainty.

  1. 01

    Define behavior

    Player-visible outcome, failure cases, and platform constraints.

  2. 02

    Scope the seam

    Server/client boundaries, integration points, and acceptance tests.

  3. 03

    Build and verify

    A focused module in the existing codebase, with reviewable evidence.

  4. 04

    Hand off cleanly

    Usage notes, limitations, and the next sensible milestone.
